# 如何写一篇 Markdown 文章

Markdown 常用写法如下：

## 标题
使用 `#` 到 `######` 表示不同级别标题。

## 文本样式
- **粗体**
- *斜体*
- `行内代码`

## 链接
[访问我的首页](index.html)

## 代码块
```js
function sayHi(name) {
  console.log("Hello, " + name);
}
```

## 有序列表
1. 先写标题
2. 再补正文
3. 最后发布

## 引用
> 写作最难的是开始，先写出来再优化。

## 表格
| 语法 | 示例 |
| --- | --- |
| 粗体 | `**文本**` |
| 斜体 | `*文本*` |
