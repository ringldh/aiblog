# 项目代码导读（新成员必读）

## 1. 技术栈

- Node.js：本地服务、构建脚本、测试
- 原生 HTML/CSS/JavaScript：前端页面
- Markdown 渲染：`marked` + `DOMPurify`
- 代码高亮：`highlight.js`
- 数据存储：`posts/*.md` + `posts/index.json`
- 版本管理：Git

## 2. 目录结构

```txt
assets/
  editor.js      编辑页交互（登录/发布/草稿/摘要）
  main.js        首页列表加载
  markdown.js    Markdown 渲染、目录提取、代码高亮入口
  post.js        文章详情页渲染
  site.js        社媒链接配置加载
  style.css      全站样式

posts/
  *.md           文章源文件
  index.json     索引（脚本生成）
  .ai-summary-cache.json   摘要缓存（git忽略）

scripts/
  dev-server.js      本地 HTTP 服务 + API + 编辑器鉴权
  generate-index.js  扫描文章并生成索引/摘要
  check-content.js   索引校验

tests/
  dev-server-auth.test.js
  generate-index.test.js
```

## 3. 运行入口

`package.json` 里最重要的脚本：
- `start`: `build` 后启动服务
- `build`: 生成索引 + 校验
- `serve`: 启动 `scripts/dev-server.js`
- `test`: 运行 Node 原生测试

## 4. 核心调用链

## 4.1 发布文章

1. 编辑页 `assets/editor.js` 调 `submitPublish()`
2. `POST /api/publish`
3. `scripts/dev-server.js` 写入 `posts/{slug}.md`
4. 触发 `scripts/generate-index.js`
5. 首页/文章页刷新后读取新索引

## 4.2 保存草稿

1. 编辑页点“保存草稿”
2. `submitPublish({ forceDraft: true })`
3. 后端写 front matter：`draft: true`
4. 生成索引时自动跳过草稿

## 4.3 AI 摘要

实时（编辑页按钮）：
- `assets/editor.js -> /api/summary`
- `scripts/dev-server.js -> OpenAI-like /chat/completions`

批量（构建）：
- `scripts/generate-index.js`
- 根据 `aiSummary.mode` 判断是否调用
- 命中 `posts/.ai-summary-cache.json` 则不重复生成

## 5. 鉴权与安全

文件：`scripts/dev-server.js`

机制：
- 编辑器登录接口：
  - `GET /api/editor/auth-status`
  - `POST /api/editor/login`
  - `POST /api/editor/logout`
- 会话：
  - 使用 HMAC 签名 token（Cookie）
  - 支持服务重启后继续校验（不依赖内存 session）
- 防暴力破解：
  - 最大失败次数 `editorAuth.maxAttempts`
  - 冷却时间 `editorAuth.cooldownMinutes`

受保护接口：
- `POST /api/summary`
- `POST /api/publish`

## 6. Markdown 渲染

文件：`assets/markdown.js`

核心方法：
- `renderMarkdown(markdown)`
  - `marked.parse()` 解析
  - `DOMPurify.sanitize()` 清洗
  - 提取标题并生成目录（TOC）
- `applyCodeHighlight(root)`
  - 使用 `highlight.js` 高亮代码块

页面使用：
- `assets/post.js`：渲染 TOC + 正文
- `assets/editor.js`：渲染预览并高亮代码

## 7. 配置文件说明

## 7.1 `blog.config.json`

- `excerptLength`：正文摘录长度
- `editorAuth.enabled`：编辑器密码保护开关
- `editorAuth.passwordEnv`：密码环境变量名
- `editorAuth.sessionSecretEnv`：会话签名密钥环境变量名
- `editorAuth.maxAttempts` / `cooldownMinutes`：登录失败限制
- `aiSummary.*`：摘要模型配置

## 7.2 `site.config.json`

用于前端社媒链接展示，默认包含：
- Bilibili
- 抖音
- 小红书

## 8. 关键函数速查

`scripts/dev-server.js`
- `createServer(options)`: 创建 HTTP 服务
- `getEditorAuthSettings(config)`: 读取鉴权策略
- `createSessionToken()` / `verifySessionToken()`: 会话签名与校验
- `publishPost(payload)`: 写文件 + 重建索引
- `buildSimpleDiff()`: 冲突差异展示

`scripts/generate-index.js`
- `readFrontMatter()`: 解析元信息
- `shouldUseAiSummary()`: 摘要策略判断
- `resolveAiSummary()`: 缓存优先 + AI 回退

`assets/editor.js`
- `refreshAuthState()`: 同步登录状态并锁定按钮
- `buildFrontMatterPreview()`: 前置展示元信息
- `submitPublish()`: 发布/覆盖/草稿全流程

## 10. 常见排查

- 无法登录编辑器：
  - 检查 `editorAuth.enabled`
  - 检查 `EDITOR_PASSWORD` 是否设置
  - 检查是否触发登录冷却
- 摘要失败：
  - 检查 `OPENAI_API_KEY`
  - 检查 `aiSummary.baseURL/model/apiKeyEnv`
- 发布成功但首页不显示：
  - 检查是否 `draft: true`
  - 运行 `npm run generate:index` 并检查 `posts/index.json`
