# 项目代码导读（新成员必读）

## 1. 技术栈

- Node.js：本地服务、构建脚本、测试
- 原生 HTML/CSS/JavaScript：前端页面
- Markdown 渲染：`marked` + `DOMPurify`
- 代码高亮：`highlight.js`
- 数据存储：`posts/*.md` + `posts/index.json`

## 2. 目录结构

```txt
assets/
  editor.js      编辑页交互（登录/发布/草稿/摘要）
  manage.js      管理页交互（列表/删除/切换草稿）
  main.js        首页列表加载
  markdown.js    Markdown 渲染、目录提取、代码高亮入口
  post.js        文章详情页渲染
  site.js        社媒链接配置加载
  style.css      全站样式

posts/
  *.md                 文章源文件
  index.json           索引（脚本生成）
  .ai-summary-cache.json   摘要缓存（git忽略）

scripts/
  dev-server.js      本地 HTTP 服务 + API + 编辑器鉴权
  generate-index.js  扫描文章并生成索引/摘要
  check-content.js   索引校验
  run-tests.js       测试入口

tests/
  dev-server-auth.test.js
  generate-index.test.js
```

## 3. 核心页面

- `/index.html`：文章列表页
- `/post.html`：文章详情页（AI 摘要 + 目录 + 代码高亮）
- `/editor.html`：写作页（登录后可发布/草稿/摘要）
- `/manage.html`：管理页（登录后可删除、切换草稿）

## 4. 服务端 API（`scripts/dev-server.js`）

鉴权：
- `GET /api/editor/auth-status`
- `POST /api/editor/login`
- `POST /api/editor/logout`

业务：
- `POST /api/summary`
- `POST /api/publish`
- `GET /api/posts/manage`
- `POST /api/posts/set-draft`
- `POST /api/posts/delete`

## 5. 关键调用链

发布：
1. `assets/editor.js -> submitPublish()`
2. `POST /api/publish`
3. `scripts/dev-server.js -> publishPost()`
4. 写入 `posts/{slug}.md`
5. 调 `buildIndex(root)` 更新索引

管理页切换草稿：
1. `assets/manage.js -> toggleDraft()`
2. `POST /api/posts/set-draft`
3. `scripts/dev-server.js -> setPostDraft()`
4. 重新生成索引

管理页删除：
1. `assets/manage.js -> deletePost()`
2. `POST /api/posts/delete`
3. 删除 md 文件并重新生成索引

## 6. 安全机制

- 编辑器接口需要登录态 Cookie
- 会话 token 使用 HMAC 签名
- 登录失败有次数限制与冷却锁定

主要配置（`blog.config.json`）：
- `editorAuth.enabled`
- `editorAuth.passwordEnv`
- `editorAuth.sessionSecretEnv`
- `editorAuth.maxAttempts`
- `editorAuth.cooldownMinutes`
